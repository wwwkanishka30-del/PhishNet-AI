IDN Homograph & Punycode Spoofing

Attackers register Internationalized Domain Names (IDNs) containing Cyrillic, Greek, or Latin lookalike glyphs (homoglyphs) that appear identical to legitimate brands in browsers, such as Cyrillic 'а' (U+0430) replacing Latin 'a' (U+0061).

Example Attack Vector:
https://xn--pypal-4ve.com/signin
(Decodes visually to: "pаypal.com" using Cyrillic 'а')

Subdomain Brand Hijacking

Because smartphone address bars truncate lengthy URLs, attackers place target brand names and security keywords inside subdomains, while the actual registered domain belongs to the malicious actor.

Example Attack Vector:
https://paypal.com.account-update.xyz/login
(Registered domain is 'account-update.xyz', NOT paypal.com)

Authority Delimiter '@' Exploitation

In RFC 1738/3986 URL syntax, characters before the '@' sign are interpreted as user credentials (username:password), while network routing directs the browser strictly to the host following the '@'.

Example Attack Vector:
https://accounts.google.com@evil-attacker.net/auth
(Browser connects to evil-attacker.net, ignoring google.com)

Open Redirect Vulnerability Abuse

Adversaries abuse legitimate enterprise websites that accept unvalidated redirect parameters (`?url=`, `?dest=`, `?r=`) to bypass email filters, redirecting the user immediately to a malicious credential harvester.

Example Attack Vector:
https://trusted-site.com/redirect?dest=https://phish.xyz
(Filter trusts trusted-site.com, victim ends up on phish.xyz)

Bare IP Hostnames & Obfuscated Ports

Phishers host fast-flux landing pages on compromised residential IoT devices or VPS instances using bare IP addresses (or decimal/hex representations like 2130706433) on non-standard ports (2082, 8888, 7080).

Example Attack Vector:
http://198.51.100.24:8888/bank/login.php
(Direct IP bypasses domain registration age tracking)

Disposable TLDs & Chained Keywords

Free and low-cost Top-Level Domains (.xyz, .top, .buzz, .cfd, .tk) feature frequently in automated phishing kits. Domains concatenate words like "security-update-verify" to create synthetic urgency.

Example Attack Vector:
https://chase-security-verification-alert.top/signin
(Chained hyphens + high-abuse TLD registry)

Safe Browsing & Verification Checklist

Defense Best Practices
✓
Inspect the Effective TLD + 1

Always identify the true registered domain (the label immediately preceding `.com`, `.org`, etc.) rather than trusting subdomains.

✓
HTTPS Does Not Equal Safe

Over 80% of phishing sites use free Let's Encrypt TLS certificates. The padlock only indicates encryption in transit, not legitimacy.

✓
Never Rely on Email Links for Auth

If a service alerts you to account suspension or billing issues, navigate manually to the official website via bookmark or direct search.

✓
Use FIDO2 / Hardware Security Keys

FIDO2/WebAuthn credentials bind authentication challenges to the browser's origin, making them cryptographically immune to proxy phishing.
