About PhishNet AI

An AI-powered cybersecurity platform designed to protect users by dissecting URLs, exposing deceptive patterns, and computing explainable risk scores before links are visited.

Student Portfolio: M.Tech in Computer Science & Engineering Domain: Applied Cybersecurity & Machine Learning

Dual-Engine Architecture: Defense-in-Depth

Heuristics + ML Extension

PhishNet AI combines deterministic rule-based explainability with statistical machine learning classification. Rather than treating detection as an opaque black box, every score output provides clear technical justification and actionable defense recommendations.

Engine 1 15-Feature Heuristic Rules

Extracts structural, lexical, and brand-deception indicators including IPv4/IPv6 hosts, userinfo '@' character spoofing, Punycode/IDN homographs, excessive hyphens, chained subdomains, open redirect query patterns, and abused TLD registries.

Output: 0–100 Weighted Risk Score & Explanations
Engine 2 Random Forest ML Classifier

Converts URLs into a 12-dimensional numerical vector and evaluates them through an ensemble of 100 decision trees. Trained on documented benchmark datasets with stratified validation to prevent data leakage.

Output: Binary Classification (Phishing vs Legitimate) & Confidence

Academic Rigor & Cybersecurity Limitations

Important Disclaimers

In cybersecurity engineering, no static analysis system is infallible. PhishNet AI is designed with full transparency regarding false positive and false negative scenarios:

  • Zero Remote Network Connections: To protect users and prevent Server-Side Request Forgery (SSRF), PhishNet AI operates in an isolated local sandbox. It does not initiate HTTP requests to target hosts or download web assets.
  • False Negatives: A "Low Risk" score indicates that no known lexical anomalies or heuristic traps were found in the URL string. It does not guarantee that the website is safe; sophisticated attackers frequently register clean, normal-looking domains for zero-day phishing campaigns.
  • False Positives: Legitimate multi-tenant enterprise cloud platforms (e.g. AWS S3 buckets, complex SaaS dashboards) occasionally utilize deeply nested subdomains and long tokenized query parameters that may trigger elevated heuristic scores.
  • Continuous Threat Evolution: Cyber adversary tactics evolve constantly. URL heuristics should always be deployed as part of an end-to-end layered defense alongside multi-factor authentication (MFA/FIDO2) and endpoint protection.
